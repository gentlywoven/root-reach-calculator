Faction selection simulation

10,000 independent random complete selection attempts for every player and bot configuration in the app. Each trial starts with the default faction state and no bans or existing picks.

Bars show how many trials included each faction. Percentages use all 10,000 trials as the denominator, so each faction’s share is its selection frequency, and totals can exceed 100% because each game selects several factions. The algorithm uses sequential random choice among currently available factions, so this is an empirical result, not an equal probability guarantee.
